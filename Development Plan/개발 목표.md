# Project ReverseTowerDefense
플레이어의 관점이 바뀐 디펜스게임을 만든다.

## 개발 사용
- Unity 6.3 LTS
- 
- Visual Studio Code (+Codex)

## 개발 목표
- 포트폴리오에 사용할 게임 제작.
- 직접 구상하고 구현한 코드를 50% 이상 사용.
- GitHub 및 Notion 등록.

## 주요 시스템
### 패 드로우 시스템
- 몬스터 / 강화 2가지 덱 시스템
- 시작시 몬스터 5장, 강화 3장 을 가지고 시작
- 웨이브 종료 or 중급몬스터 사망 시 패 보충
    웨이브 종료 = 몬스터 1장 or 강화 2장
    중급몬스터 사망 = 몬스터 1장 and 강화 2장 
### 몬스터 설정
- 몬스터 구성
    * 몬스터 필드
    일반몬스터 3칸 중급몬스터 1칸 보스 1칸 구성
    시작시 드로우한 몬스터 5장으로 다 채움

    * 몬스터 종류 및 능력
        - 슬라임
        체력 높음, 물리저항 높음, 마법저항 낮음, 이동속도 느림
        - 고블린
        체력 준수, 물리저항 준수, 마법저항 높음, 이동속도 준수
        - 울프
        체력 낮음, 물리저항 준수, 마법저항 준수, 이동속도 빠름
        - 오거
        체력 준수, 물리저항 높음, 마법저항 준수, 이동속도 준수
        - 골렘
        체력 높음, 물리저항 낮음, 마법저항 높음, 이동속도 느림

    * 몬스터의 기본 스팩
        - 일반 몬스터
        체력 100, 물리저항 20, 마법저항 20, 이동속도 2

        - 중급 몬스터
        체력 1000, 물리저항 60, 마법저항 60, 이동속도 2

        - 보스 몬스터
        체력 4000, 물리저항 150, 마법저항 150, 이동속도 2

        - 수치 반영
        높음 = + 150%, 준수 = 100%, 낮음 = 50%
- 몬스터 카드 진화
    몬스터 카드의 기본 스팩을 2배 성장시킨다.
    * 조건
        - 필드 / 패 / 패 동일 카드가 3장 = 필드카드 진화 가능
        - 패 / 패 / 패 동일 카드가 3장 = 패카드 진화 가능

    * 부과효과
        - 슬라임
            몬스터 사망시 1/4 능력을 가진 개체 2개 생성
        - 고블린
            몬스터 은신부여
        - 울프
            몬스터 회피율 부여
        - 오거
            몬스터 재생력 부여
        - 골렘
            체력증가, 저지불가 부여


- 몬스터 강화
    몬스터 카드를 강화시킨다.
    단, 웨이브중 강화한 수치는 웨이브가 종료후 반영된다.

    체력 / 물리방어 / 마법방어 / 이동속도

    체력 + 10%
    물리방어 + 10%
    마법방어 + 10%
    이동속도 + 2%

    * 강화 한도
        - 최대 일반 강화 20
        - 카드 진화 강화 25

    예) 
    일반강화) 슬라임 - 체력 10, 물리저항 5, 마법저항 5
    진화강화) 슬라임 - 체력 10+2, 물리저항5, 마법저항 5+3

    * 카드 진화 조건
        동일 카드 3장 패에 존재시 진화가능

- 몬스터 스폰
    * 일반 몬스터
        - 몬스터 필드의 일반 몬스터존 3장을 스폰
        - 생성수는 9마리로 시작하여 3의 배수
        - 생성순서는 몬스터 필드의 일반 몬스터존 3장의 순서

    * 중급 몬스터 
        - 몬스터 필드의 중급 몬스터존 1장을 스폰
        - 생성후 개체 소멸시 쿨타임을 가짐
        - 디펜스 AI의 생성요청에 의하여 생성됨.
  
    * 보스 몬스터
        - 몬스터 필드의 보스 몬스터존 1장을 스폰
        - 10 라운드마다 생성됨

### 디펜스 설정
타워디펜스를 진행할 AI 생성
- 타워의 종류
    물리 / 마법

- 타워의 강화
    * 최대 강화수치 7
        - 일반강화 3
        - 마나강화 3
        - 진화강화 1
    * 물리
        우선목표 = 범위 내 선두개체

        - 다중 
            3개체를 동시에 공격한다.
            업그레이드당 +1 개체
            한발당 데미지 비율 50% / 진화시 50 > 80
        - 관통
            최대 2개체에게 데미지를 부여한다.
            2 업그레이드당 +1 개체 / 진화시 +1
            업그레이드당 데미지 + 10% / 진화시 + 20%
        - 범위
            범위 내 모든 개체에게 데미지를 부여.
            공격 범위 1 범위 내 데미지 부여
            업그레이드당 + 0.1 범위 / 진화시 0.1 > 0.2  
    * 마법
        - 도트
            공격한 대상에게 도트데미지 부여
            초당 최대 체력의 1% 데미지 부여
            중복부여 불가능 / 우선목표 비 도트부여 객체 우선
            업그레이드당 + 1% / 진화시 1 > 2
            (보스 제외) 
            일반 도트비율 1 > 0.1(4천기준 1레벨 데미지 4)
            진화 도트비율 2 > 0.2(4천기준 7레벨 데미지 56)
        - 둔화
            공격 불가능
            타워 중심으로 5*5 둔화범위 생성
            범위 내 이동속도 20% 저하.
            일반업그레이드 + 3% (9%)
            마나업그레이드 + 4% (12%)
            진화업그레이드 + 9%
            최대 이동속도 50% 저하
        - 속박
            공격대상 1개체, 속박시간 2초, 쿨타임 8초 ,데미지 낮음
            일반업그레이드 + 1개체
            마나업그레이드 + 속박시간 0.5초
            진화업그레이드 + 쿨타임 2초감소
        - 블럭
            공격 불가능
            타워중심 3*3 범위 내 2초간 길을 막는 블럭생성
            일반, 마나 업그레이드 + 지속시간 0.2초
            진화업그레이드 + 지속시간 0.3초
